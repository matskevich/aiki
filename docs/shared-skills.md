# portable shared skills

this delivery contains three generic packages under `skills/`:

- `outcome-continuity`: preserve the goal, task/operation identity and useful
  continuation, with evidence appropriate to the actual outcome.
- `attention-and-authority`: recover prior authority, act on available work and
  ask only for a consequential missing decision, without inventing a risk budget.
- `reality-learning`: turn an episode into a technical improvement, contextual
  recipe, general principle or private preference, keeping raw evidence private.

each folder has a `SKILL.md` entry. use a compatible agent's normal skill loader
or explicitly supply the entry for a task. the catalog planner does not install
these packages. installing one grants no access to accounts and does not replace
the adopter's personal policy, budgets, source context or provider confirmations.

these are newly authored portable instructions. the maintainer's larger personal
skills and case memory keep their private owners and are not copied wholesale.
the [learning example](../examples/learning-record.json) is synthetic, not a claim
that the packages have been independently accepted in every agent client.
