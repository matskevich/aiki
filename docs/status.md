catalog readiness is a dated, reviewed description. `live_status=not_checked`
means these commands do not probe a provider. installation-local evidence must
name the actual version, host, client, account boundary, operation and observed
effect. a repository being synchronized does not establish a working runtime.

sanitized receipts. do not represent personal deployment evidence as broad
recipient support.

own life. the former pagi repository name redirects here. the
