# contributing

start with [the agent entry](AGENTS.md). explain the outcome you want to improve,
the affected component and the smallest evidence that would establish success.
changes to a linked provider belong in its source repository.

use a separate branch and pull request. run `python3 tools/catalog.py check`.
keep required and optional dependencies distinct. document source visibility and
readiness without implying live account access. a new recipe needs a useful
result, restart and rollback evidence from its intended consumer.

use synthetic examples and retain private feedback in its originating case.
never attach credentials, sessions, real correspondence or personal task data.
new contributions to this repository use its mit license; third-party material
must preserve its original license and attribution.
